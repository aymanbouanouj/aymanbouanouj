# AB mark provenance

The *shape* of the AB monogram and purple arrow was traced from the screenshot of the user's own GitHub profile. It is not an original redesign of somebody else's logo. The logo paths are committed in `scripts/brand_paths.py`; the screenshot is **not** included or required at runtime. For full fidelity (metallic gradients, edge details), the user should provide their original logo SVG/PNG. Do not redistribute the monogram separately without the owner's authorization.

The rest of the profile layout, terminal panels, SVG generation, and tests were authored independently rather than copied from the reference developer's repository. GitHub's own UI (avatar, follower sidebar, Achievements, Pinned repos) cannot be replaced by README content.
