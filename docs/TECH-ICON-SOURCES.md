# Technology icon sources and rights

All icon paths are vendored in `scripts/tech_icon_paths.json`. There is **no runtime image service**, font, script or network call for icons.

- [Simple Icons](https://github.com/simple-icons/simple-icons), [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md): PHP, JavaScript, HTML, CSS, Laravel, Tailwind CSS, Vite, Python, React.
- [Devicon](https://github.com/devicons/devicon), [MIT](https://github.com/devicons/devicon/blob/master/LICENSE), Copyright (c) 2015 konpa: PowerShell pictogram.
- Blade uses a custom generic code-bracket pictogram; **not an official trademark icon**.

Only verified GitHub Linguist language records and verified public dependency manifests can populate the card. Unknown names receive a neutral fallback monogram. Icon assets are third-party marks and the project's general copyright notice does not override their respective rights.
